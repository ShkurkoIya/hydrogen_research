# 🛰️ RustGeoH2 — Облачный ГИС-движок поиска природного водорода на чистом Rust

Высокопроизводительный аналитический движок для автоматизированного скрининга спутниковых и геофизических данных с целью выявления поверхностных проявлений природного (геологического) водорода (H₂).

Написан на **100% чистом Rust** без тяжёлых C/C++ зависимостей (без GDAL, Python и PROJ), с прямой потоковой вычиткой Cloud Optimized GeoTIFF (COG) по HTTP `Range`-запросам и векторизованной аналитикой на базе **Polars / Apache Arrow**.

---

## 🎯 Бизнес-задача и ценность продукта

Полевая геологоразведка на больших территориях (тысячи квадратных километров в Якутии и других регионах) требует огромных затрат на вездеходы, экспедиции и бурение.

**Что делает система:**
Система не заменяет полевых геологов и не обещает «найти газ по одному пикселю». Она выступает как **высокоскоростной радар перспективных зон**:

1. Перемалывает многолетние архивы спутниковых снимков (Sentinel-2, DEM) и геофизические карты.
2. Отсекает ложные цели (озёра, термокарст, гари, вырубки, застройку, облака).
3. Выдаёт ранжированный список **топ-N кластеров аномалий** (координаты `lat/lon`, площадь, уверенность), куда полевая бригада выезжает с ручными газоанализаторами. Это сокращает объём холостых полевых маршрутов в 5–10 раз.

## 🔬 Физическая и геологическая модель поиска

Молекулярный водород (H₂) прозрачен для оптических спутников, поэтому поиск строится на **мультифакторном анализе косвенных поверхностных маркеров** («ведьминых кругов» / *fairy circles*):

1. **Угнетение растительности (NDVI):** Просачивающийся из недр водород вытесняет кислород из почвенного воздуха и изменяет pH, подавляя корневую систему растений. На снимках формируются округлые зоны с аномально низким `NDVI` относительно окружающего фона.
2. **Минералогический отклик (SWIR / Железистые породы):** Генерация H₂ происходит при серпентинизации (реакции воды с железистыми и ультраосновными породами). В коротковолновом ИК-диапазоне (`B11`, `B12`) фиксируются аномалии оксидов железа и карбонатных корок (`Ferrous Minerals Ratio = B11 / B08`).
3. **Микрорельеф (`cop-dem-glo-30`):** Растворение и проседание пород над каналами дегазации формирует замкнутые округлые просадки глубиной 1–3 метра.
4. **Мульти-временная стабильность:** Истинные зоны дегазации сохраняют контур годами, в отличие от лесных пожаров, распашки или сезонных луж.
5. **Геологическая маска (Породы и разломы):** Повышенный весовой коэффициент присваивается аномалиям, расположенным вдоль глубинных разломов, магнитных аномалий и трапповых/кимберлитовых полей.

## 🏗️ Текущая архитектура и стек

### Технологический стек

* **Язык и сборка:** Rust (`edition 2021`/`2024`), линковщик **`mold`** + `sccache` для быстрой итеративной компиляции.
* **STAC и облачное хранилище:** `stac-async`, `stac-api`, `reqwest` (поиск сцен, фильтрация по `eo:cloud_cover` и `s2:nodata_pixel_percentage`, автоматическая подпись URL через SAS API).
* **Чтение растров без GDAL:** `async-tiff` + кастомный `ReqwestRangeReader` (чтение заголовков IFD, динамическое определение сетки тайлов, параллельная выгрузка сетки `N×N` тайлов по HTTP `Range` и бесшовная склейка в памяти).
* **Геодезия:** `proj4rs` (перевод WGS84 `lon/lat` в метрические проекции UTM).
* **Аналитический движок:** `polars` (ленивые вычисления `LazyFrame`, расчёт спектральных индексов, перцентилей и кольцевых буферов).

### Целевая модульная структура (Архитектура «Конструктор»)

Для переиспользования кода в **Axum REST API**, **мультиагентных воркерах** и **CLI/ноутбуках** система разделена на 3 изолированных слоя:

```text
src/
├── main.rs                  # Тонкий оркестратор сценариев / CLI
├── cube.rs                  # Canonical Data Model: RasterCube и SensorProfile
├── source.rs                # Трейт RasterSource (абстракция над COG, Zarr, S3/MinIO)
├── sensors.toml             # Декларативные профили калибровки (scale, offset, nodata)
├── catalog/
│   └── planetary.rs         # Адаптер Microsoft Planetary Computer STAC + SAS-подпись
├── cog/
│   └── range_reader.rs      # RemoteCog: Range-запросы, метаданные IFD, склейка сеток тайлов
└── analytics/
    └── spatial_stats.rs     # Чистые CPU-функции на Polars (готовы для tokio::spawn_blocking)
```

> **Принцип калибровки:** Аналитическое ядро работает исключительно с физическими коэффициентами отражения (`0.0 .. 1.0`). Приведение сырых значений из растров выполняется на уровне загрузчика по единой формуле:
> `Physical Value = Raw Value * scale + offset`
> *(Например, для Sentinel-2 L2A после января 2022 года учитывается ESA Radio Offset: `scale = 0.0001`, `offset = -0.1`, что эквивалентно вычитанию `1000` из сырых `u16`).*

## ✅ Проверенный бенчмарк (Ground Truth: Буракебугу, Мали)

Пайплайн проверен на эталонном промышленном месторождении природного водорода **Буракебугу** (`13.002° N, -5.130° W`, концентрация H₂ в скважинах до 98%).

* **Параметры теста:** Сцена `S2A_MSIL2A_20240317T103751...`, разрешение 10 м, бесшовная сетка `3×3` тайла (`1536×1536 px` = `15.3×15.3 км`), сравнение зоны скважин (`0–800 м`) с окружающим фоновым кольцом (`1.6–3.5 км`).
* **Результаты расчёта (Polars):**

| Зона | Валидные пиксели (10м) | Средний `NDVI` | `P10 NDVI` (очаги стресса) | Отражение в NIR (`B08`) |
| :--- | :---: | :---: | :---: | :---: |
| **`H2_Wells_0_800m`** (скважины) | `20 081` (99.9% круга) | **`0.1755`** | **`0.1294`** | **`0.3824`** |
| **`Savanna_Ring_1.6_3.5km`** (фон) | `304 396` | **`0.2147`** | **`0.1453`** | **`0.3654`** |

**Вывод:** Прямо над водородным куполом фиксируется устойчивое снижение индекса вегетации на **18.3%** и рост отражения в ближнем ИК-диапазоне на **4.7%** (осветлённая почвенная корка в зонах дегазации).

## ⚠️ Специфика региона Якутии (Ограничения и фильтры)

При переносе алгоритма с засушливой саванны Мали на Сибирскую платформу (Якутия) необходимо учитывать 3 региональных фактора:

1. **Термокарст и аласы:** Таяние вечной мерзлоты создаёт тысячи округлых просадок, визуально похожих на «ведьмины круги». Отсеиваются через водный индекс `NDWI` и анализ многолетней динамики.
2. **Узкое сезонное окно:** Бесснежные снимки без облаков доступны только в период **с конца июня по август**.
3. **Приоритетные геологические зоны:** Максимальный потенциал — борта Вилюйской синеклизы, Мирнинский и Удачнинский районы (зоны глубинных разломов, траппового магматизма и кимберлитовых полей, где уже фиксировались попутные водородные газопроявления).

## 🗺️ Roadmap (Стратегия развития)

### Этап 1: Рефакторинг и унификация ядра (Текущий фокус)

* [ ] Вынести `RasterCube`, `SensorProfile` и трейт `RasterSource` в библиотечный крейт.
* [ ] Реализовать авточтение `scale` / `offset` / `nodata` из STAC (`raster:bands`) с фолбэком на `sensors.toml`.
* [ ] Интегрировать канал **`SCL` (Scene Classification Layer)** для автоматического отсева облаков, теней, воды и снега.

### Этап 2: Слепой сканер площадей и мультиспектральный скоринг (MVP для заказчика)

* [ ] Подключить 20-метровый канал **`B11` (SWIR)** для расчёта индекса железистых пород (`B11 / B08`).
* [ ] Подключить цифровую модель рельефа **`cop-dem-glo-30`** для поиска замкнутых микропросадок.
* [ ] Реализовать **Grid Scanner**: разбиение квадрата `20×20 км` на ячейки `250×250 м`, расчёт локального Z-score по 3 факторам (`NDVI` + `SWIR` + `DEM`) и кластеризацию соседних аномалий.
* [ ] **Валидация:** Прогнать сканер вслепую на квадрате Мали (убедиться, что скважины Буракебугу попадают в топ-3) и на тестовом участке в Якутии.
* [ ] Экспорт результатов в **GeoJSON / GeoParquet** для открытия в QGIS и полевых навигаторах.

### Этап 3: Мульти-временной анализ и геологические маски

* [ ] Добавить агрегацию по временному ряду (3–5 летних снимков за разные годы) для отсева гарей, вырубок и свежего термокарста.
* [ ] Добавить поддержку векторных масок заказчика (`.shp` / `.geojson` через `geozero` / `geo`) — буферизация вдоль линий разломов и наложение магнитных аномалий (EMAG2 / аэромагнитка).

### Этап 4: Интеграция в облачный бэкенд и мультиагентную систему

* [ ] Обернуть аналитический пайплайн в **Axum REST API** (асинхронная выкачка данных в `tokio` + CPU-расчёты `Polars` внутри `tokio::task::spawn_blocking`, отдача результатов в JSON и бинарном Apache Arrow IPC).
* [ ] Подключить локальный S3/MinIO кэш (`RasterCube`) и адаптер **Zarr (`zarrs`)** для многомерных кубов данных.
* [ ] Оформить модули поиска и скоринга как **Tools** для AI-агентов (автоматический мониторинг новых пролётов спутников и генерация отчётов по лицензионным участкам).

## 🚀 Быстрый старт (Arch Linux)

```bash
# 1. Установка сверхбыстрого линковщика mold для ускорения сборки
sudo pacman -S mold gcc

# 2. Настройка ~/.cargo/config.toml
mkdir -p ~/.cargo
cat << 'EOF' > ~/.cargo/config.toml
[target.x86_64-unknown-linux-gnu]
linker = "gcc"
rustflags = ["-C", "link-arg=-fuse-ld=mold"]
EOF

# 3. Запуск бенчмарка
cargo run --release
```
